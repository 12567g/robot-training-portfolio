## 接线说明

### 供电与信号连接（基于实测接线图）

```
3S 锂电池 (11.1V)
    │
    ├─→ [3S 40A ESC] ──→ 50mm 涵道无刷电机 (4300KV, 三相线)
    │       ↑
    │       └── PWM调速信号 ← ESP32-S3 (任意PWM引脚)
    │
    └─→ [MP1584 降压模块] (11.1V→5V)
            │
            ├─→ 5V / GND → ESP32-S3 主控
            │
            └─→ 5V / GND → MX1508 驱动板 (VM接5V)
                    │
                    ─→ GPIO16/17/18/19 → IN1/IN2/IN3/IN4
                            │
                            ─→ OUT1~OUT4 → 2×N20 有刷减速电机 (差速行走)

所有器件共地（公共GND）
```

## 测试台架

### W2 低压台架验证项
1. **两轮驱动验证**：ESP32编译与网页命令，模拟断联并测试停车
2. **MP1584带载测试**：测5V纹波/压降，确认稳定供电

### W4 授权台架验证项（需专项授权）
1. **吸附力测量**：不同工况下的输入功率、压差与有效吸附力
2. **EDF高速运转安全**：固定台架+防护挡板+授权人员在岗
3. **密封对比实验**：至少两种裙边方案的压差/拉力对比
