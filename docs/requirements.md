# 目标与验收要求

## 1. 目标

在六周内复现负压吸附爬壁机器人，达到"水平面安全移动 + 可重复的静态吸附力测量 + 实验报告"。

## 2. 成功标准

| 编号 | 标准 | 验证方式 | 状态 |
|---|---|---|---|
| A-1 | 水平面安全移动：直线、转向、限速、急停有效 | 视频 + 3 次重复记录 | 待验证 |
| A-2 | 静态吸附力测试可重复：≥3 工况 × ≥3 次 | 原始 CSV + 曲线 | 待验证 |
| A-3 | 实验报告完整：假设、方法、数据、结论 | reports/ 正式报告 | 待写 |
| A-4 | 系统可复现：按 docs 从零装出同一台 | 复现步骤文档 | 待写 |
| A-5 | 预算 ≤2000 元且账实一致 | BOM 实际账 | 待编 |

## 3. 不做什么

- 未获批准的垂直爬升（W6 前不申请）
- 未经安全审查的整机上电
- 购买 N52 级大尺寸裸强磁（磁吸赛道才涉及，本项目不涉及）
